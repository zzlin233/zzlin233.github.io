这是一篇示例文章。你的博客主题**仿照 [jyywiki.cn](https://jyywiki.cn/)**
的风格设计：内容至上、极简排版、红黑配色。下面简单介绍如何使用。

> #### 💡 一句话
>
> 写博客 = 在 `_posts/` 目录里新建 Markdown 文件，然后 `git push`。

## 目录结构

```
├── _config.yml          # 站点配置(标题、导航、URL 等)
├── _posts/              # 博客文章, 命名 YYYY-MM-DD-标题.md
├── _layouts/            # 布局模板
├── _includes/           # 头部 / 页脚 / 元信息等片段
├── assets/css/style.scss
├── assets/js/main.js
├── archive.html         # 归档
├── tags.html            # 标签
└── about.html           # 关于
```

## 新建一篇文章

在 `_posts/` 中创建文件即可，文件名以日期开头：

```markdown
---
title: 我的第一篇文章
date: 2025-06-01 09:00:00 +0800
tags: [随笔]
---
正文写在这里……
```

文章会出现在[首页]({{ '/' | relative_url }})、[归档]({{ '/archive.html' | relative_url }}) 与 [标签]({{ '/tags.html' | relative_url }}) 中。

> #### ⏰ 注意
>
> 文件名中的日期会作为文章发布时间的默认值，建议保持一致。
